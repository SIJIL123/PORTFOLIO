# PORTFOLIO

My personal portfolio site. It's a static site with a custom JavaScript layer for the animations and canvas effects.

**Live site:** https://6a57ce9b4eda90baa5185340--meek-druid-1f380b.netlify.app/

## Features

- Custom cursor with a coordinate readout
- Scroll-triggered animations and section progress bars
- Canvas background with a data-flow animation
- A 3D dodecahedron canvas
- An 8086 assembler register simulation
- A contact form with client-side validation

## Structure

| File | What it does |
| --- | --- |
| `index.html` | Page markup and content |
| `style.css` | Layout and styling |
| `app.js` | Interactivity, animations and canvas effects |
| `server.py` | Small local server for previewing the site |

## Run locally

`server.py` uses only the Python standard library, so there's nothing to install.

```bash
python server.py
```

It serves the folder at `http://localhost:8080` and opens it in your browser. Press `Ctrl+C` to stop.
