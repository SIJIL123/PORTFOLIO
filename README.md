# PORTFOLIO

Personal portfolio site for **Sijil N. Varghese**, software engineer and systems architect. It is a static single-page site with a custom JavaScript layer for animations and interactive canvas effects.

## Features

- Custom cursor with coordinate readout
- Scroll-triggered animations and section progress indicators
- Canvas background with a data-flow animation
- 3D dodecahedron canvas
- 8086 assembler register simulation
- Contact form with client-side validation

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Page markup and content |
| `style.css` | Layout and styling |
| `app.js` | Interactivity, animations, and canvas effects |
| `server.py` | Small local server for previewing the site |

## Run locally

`server.py` uses only the Python standard library, so no installation is needed.

```bash
python server.py
```

The script serves the folder at `http://localhost:8080` and opens it in your browser. Press `Ctrl+C` to stop.
